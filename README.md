# Modul Pembelajaran JavaScript Dasar

## Daftar Isi

### [Pertemuan 9: Sintaks Dasar JavaScript](./pertemuan-09-sintaks-dasar-javascript.md)
**Topik Pembelajaran:**
- Sintaks Dasar: Cara menulis kode JavaScript dan menambahkan komentar
- Variabel: Penggunaan `var`, `let`, dan `const` beserta perbedaannya
- Tipe Data: Primitif (String, Number, Boolean, null, undefined) dan Kompleks (Object, Array)
- Operator: Aritmatika, Perbandingan, dan Logika

**Tujuan:** Memahami dasar-dasar syntax JavaScript dan struktur data fundamental

### [Pertemuan 10: Logika dan Struktur Kontrol](./pertemuan-10-logika-struktur-kontrol.md)
**Topik Pembelajaran:**
- **Conditional (Percabangan):**
  - If-else statements
  - Switch statements
  - Operator ternary
  - Truthy dan falsy values
- **Looping (Perulangan):**
  - For loop (traditional, for...of, for...in)
  - While loop
  - Do-while loop
  - Break dan continue statements

**Tujuan:** Menguasai kontrol alur program untuk membuat logika yang kompleks

### [Pertemuan 11: Struktur Data Inti](./pertemuan-11-struktur-data-array-object.md)
**Topik Pembelajaran:**
- **Array:**
  - Membuat dan mengakses array
  - Method untuk manipulasi: push, pop, shift, unshift, splice
  - Method untuk pencarian: find, indexOf, includes
  - Method untuk transformasi: map, filter, reduce, sort
- **Object:**
  - Membuat dan mengakses object properties
  - Method dalam object
  - Object utilities: Object.keys(), Object.values(), Object.entries()
  - Destructuring assignment
  - Kombinasi Array dan Object untuk struktur data kompleks

**Tujuan:** Memahami struktur data untuk menyimpan dan memanipulasi informasi kompleks

### [Pertemuan 12: Fungsi](./pertemuan-12-fungsi-javascript.md)
**Topik Pembelajaran:**
- **Deklarasi Fungsi:**
  - Function declaration vs expression vs arrow function
  - Kapan menggunakan masing-masing jenis
- **Parameter dan Return Value:**
  - Default parameters
  - Rest parameters dan spread operator
  - Destructuring parameters
  - Multiple return values
- **Konsep Advanced:**
  - Scope dan closure
  - Higher-order functions dan callback
  - Recursive functions
  - IIFE (Immediately Invoked Function Expression)

**Tujuan:** Menguasai fungsi untuk membuat kode yang modular dan reusable

### [Pertemuan 13: Interaksi dengan Browser (DOM Manipulation)](./pertemuan-13-dom-manipulation.md)
**Topik Pembelajaran:**
- **Apa itu DOM (Document Object Model):**
  - Konsep DOM sebagai tree structure
  - Node types dan navigation
- **Seleksi Elemen:**
  - getElementById, querySelector, querySelectorAll
  - Modern vs traditional selectors
- **Manipulasi Elemen:**
  - Mengubah content (textContent, innerHTML)
  - Manipulasi attributes dan styling
  - Menambah, menghapus, dan memodifikasi elemen
- **Event Handling:**
  - addEventListener dan event types
  - Event object dan properties
  - Event bubbling dan delegation

**Tujuan:** Membuat aplikasi web interaktif dengan manipulasi DOM dan event handling

## Struktur Pembelajaran

### Pendekatan Bertahap
Modul ini dirancang dengan pendekatan bertahap dari konsep dasar hingga implementasi praktis:

1. **Foundation (Pertemuan 9)**: Membangun pemahaman syntax dan tipe data
2. **Logic (Pertemuan 10)**: Mengembangkan kemampuan berpikir algoritmis
3. **Data Structures (Pertemuan 11)**: Mengelola data kompleks
4. **Functions (Pertemuan 12)**: Membuat kode yang modular dan efisien
5. **DOM Interaction (Pertemuan 13)**: Mengaplikasikan JavaScript untuk web interaktif

### Metode Pembelajaran
- **Teori**: Penjelasan konsep dengan contoh kode yang jelas
- **Praktik**: Latihan hands-on untuk setiap topik
- **Proyek**: Aplikasi mini untuk mengintegrasikan pembelajaran
- **Best Practices**: Tips dan pattern yang baik untuk kode yang maintainable

### Penilaian dan Tugas

Setiap pertemuan memiliki:
- **Latihan Praktik**: Exercise untuk memahami konsep
- **Tugas**: Proyek mini untuk mengaplikasikan pembelajaran
- **Studi Kasus**: Implementasi real-world scenarios

### Prerequisites
- Pemahaman dasar HTML dan CSS
- Familiar dengan text editor atau IDE
- Browser modern (Chrome, Firefox, Safari, Edge)

### Tools yang Dibutuhkan
- Text Editor: VS Code, Sublime Text, atau Atom
- Browser Developer Tools
- Node.js (optional, untuk testing di terminal)

## Hasil Pembelajaran

Setelah menyelesaikan modul ini, mahasiswa akan dapat:

1. **Menulis JavaScript** dengan syntax yang benar dan mengikuti best practices
2. **Mengimplementasikan logika** menggunakan conditional dan looping
3. **Mengelola data** menggunakan Array dan Object dengan method-method modern
4. **Membuat fungsi** yang modular, reusable, dan efisien
5. **Berinteraksi dengan DOM** untuk membuat aplikasi web yang interaktif
6. **Membangun aplikasi web sederhana** yang menggabungkan semua konsep yang dipelajari

## Proyek Akhir

Di akhir pembelajaran, mahasiswa akan mengerjakan proyek yang mengintegrasikan semua konsep:

- **Todo List App** dengan fitur CRUD lengkap
- **Calculator** dengan berbagai operasi matematika
- **Quiz Application** dengan scoring system
- **Mini E-commerce** product showcase
- **Personal Portfolio** dengan interaktif elements
